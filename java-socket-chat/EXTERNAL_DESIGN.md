# 外部設計書

## 1. システムアーキテクチャ
本システムは、中央サーバーと複数のクライアントという2つの主要コンポーネントで構成されます。
- **サーバー**: 複数のクライアントからの接続を受け入れ、メッセージを受信し、接続されている他のすべてのクライアントに中継します。
- **クライアント**: サーバーに接続し、ユーザーが入力したメッセージを送信し、サーバーから受信したメッセージを表示します。

通信プロトコルは、TCP/IPソケットに基づいています。

## 2. ユーザーインターフェース (CUI)
サーバーとクライアントの両アプリケーションは、シンプルなコマンドラインインターフェースを持ちます。

### サーバーインターフェース
- サーバーは起動時に、リッスンしているIPアドレスとポート番号を表示します。
- クライアントの接続や切断などのイベントをログに記録します。

### クライアントインターフェース
- クライアントは起動時に、サーバーのIPアドレス、ポート番号、およびニックネームの入力をユーザーに求めます。
- 接続後、ユーザーはメッセージを入力してEnterキーを押すことで送信できます。
- 受信したメッセージは、送信者のニックネームを前に付けてコンソールに表示されます。

## 3. 通信プロトコル
- メッセージは平文の文字列として送信されます。
- 各メッセージは改行文字（`\n`）で終端されます。
- サーバーは、マルチスレッドを使用して複数のクライアント接続を同時に処理します。

## 4. 主要シナリオ
- **クライアント接続**: クライアントがサーバーに接続要求を送信します。サーバーは要求を受け入れ、クライアントを処理するための新しいスレッドを確立します。
- **メッセージ送信**: クライアントがサーバーにメッセージを送信します。
- **メッセージブロードキャスト**: サーバーがメッセージを受信し、接続されている他のすべてのクライアントに転送します。
- **クライアント切断**: クライアントが接続を閉じます。サーバーはこれを検出し、対応するハンドラスレッドを終了します。
