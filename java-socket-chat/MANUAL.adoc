= 手順書

== 1. 前提条件
- Java Development Kit (JDK) 8以上がインストールされていること。
- ターミナルで `java -version` および `javac -version` を実行して、インストールを確認できます。

== 2. コンパイル方法
. ターミナルまたはコマンドプロンプトを開きます。
. `java-socket-chat` プロジェクトフォルダ内の `src` ディレクトリに移動します。
+
[source,sh]
----
cd java-socket-chat/src
----
. すべてのJavaソースファイルをコンパイルします。
+
[source,sh]
----
javac *.java
----
これにより、`src` ディレクトリ内の各 `.java` ファイルに対応する `.class` ファイルが生成されます。

== 3. アプリケーションの実行方法
. ターミナルで、`src` ディレクトリにいる状態で、次のコマンドを実行します。
+
[source,sh]
----
java Main
----
. 画面の指示に従い、起動したいモード（サーバーまたはクライアント）を選択します。
- *サーバーを選択した場合*: 使用するポート番号を入力するよう求められます。入力後、サーバーが起動します。
- *クライアントを選択した場合*: 接続先のサーバーのホスト名（またはIPアドレス）とポート番号を入力するよう求められます。入力後、クライアントが起動し、サーバーに接続します。

. クライアントを複数起動したい場合は、新しいターミナルを開き、ステップ1からの手順を繰り返してください。

== 4. 使用方法
- *メッセージの送信*: クライアントのコンソールにメッセージを入力し、`Enter` キーを押します。
- *メッセージの受信*: 他のクライアントからのメッセージは、送信者のニックネームが前に付いてコンソールに表示されます。
- *終了*: クライアントやサーバーを終了するには、そのターミナルウィンドウを閉じるか、`Ctrl+C` を押します。
