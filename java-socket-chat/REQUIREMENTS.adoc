= 要件定義書

== 1. 概要
本文書は、「Javaソケット通信を用いたCUIチャットアプリケーション」の要件を定義するものです。

== 2. 目的
本アプリケーションの目的は、Javaのソケット通信機能を学習するために、シンプルなCUIベースのチャットアプリケーションを開発することです。

== 3. 機能要件
- サーバーとクライアントは、1対多の形式で通信できること。
- 複数のクライアントがサーバーに接続できること。
- クライアントはサーバーにメッセージを送信できること。
- サーバーは、受信したメッセージを送信者以外のすべてのクライアントにブロードキャストすること。
- クライアントは、サーバーから受信したメッセージをコンソールに表示すること。
- クライアントはニックネームを設定できること。

== 4. 非機能要件
- OS: Windows、macOS、またはLinuxで動作すること。
- 実行環境: Java Development Kit (JDK) 8以上がインストールされていること。
- CUI（キャラクターユーザーインターフェース）で操作すること。
