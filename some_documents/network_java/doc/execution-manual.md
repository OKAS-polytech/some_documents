# アプリケーション実行手順書

## 1. 概要
このドキュメントは、「Javaで作るFTPツール」アプリケーションの実行方法について説明します。
アプリケーションは単一の実行可能JARファイルとしてパッケージ化されており、コマンドラインからサーバーまたはクライアントとして起動できます。

## 2. 前提条件
- **Java実行環境 (JRE) 11以上**
  - アプリケーションを実行するには、Java 11以上のバージョンがインストールされている必要があります。
  - インストールされているJavaのバージョンは、コマンドラインで以下のコマンドを実行することで確認できます。
    ```sh
    java -version
    ```

## 3. 実行可能JARファイル
ビルドプロセスによって、すべての必要なプログラムを含んだJARファイルが `target` ディレクトリに生成されます。
- `ftp-tool-1.0-SNAPSHOT-jar-with-dependencies.jar`

以降の手順は、プロジェクトのルートディレクトリ (`some_documents/network_java`) でコマンドを実行することを前提とします。

## 4. セットアップ
サーバーは、ファイルを共有するためのディレクトリを使用します。デフォルトでは、アプリケーションを実行した階層に`shared`という名前のフォルダを自動的に作成します。

サーバーを起動する前に、この`shared`フォルダを作成し、クライアントにダウンロードさせたいファイルを配置しておくことができます。

## 5. 実行手順

### 4.1. サーバーの起動
FTPサーバーを起動するには、コマンドラインで以下を実行します。引数として `server` を指定します。

```sh
java -jar target/ftp-tool-1.0-SNAPSHOT-jar-with-dependencies.jar server
```
実行後、サーバーGUIウィンドウが表示され、指定したポート（デフォルト: 8080）でクライアントの接続待機を開始します。

### 4.2. クライアントの起動
FTPクライアントを起動するには、コマンドラインで以下を実行します。引数として `client` を指定します。

```sh
java -jar target/ftp-tool-1.0-SNAPSHOT-jar-with-dependencies.jar client
```
クライアントGUIウィンドウが表示されます。サーバーのIPアドレスとポート番号を入力し、「Connect」ボタンをクリックすることで、サーバーに接続できます。接続が成功すると、サーバー上のファイル一覧が左側に表示されます。

### 4.3. ファイル操作

- **ファイル一覧の表示**: サーバーに接続すると、共有ディレクトリのファイル一覧が自動的に表示されます。アップロード後は自動で更新されます。
- **ファイルのアップロード**:
  1. 「Upload」ボタンをクリックします。
  2. ファイル選択ダイアログが表示されるので、アップロードしたいファイルを選択します。
  3. アップロードが開始され、完了するとチャットエリアに通知されます。
- **ファイルのダウンロード**:
  1. 左側のファイル一覧から、ダウンロードしたいファイルを選択します。
  2. 「Download」ボタンをクリックします。
  3. 保存先のディレクトリを選択するダイアログが表示されるので、保存場所を決定します。
  4. ダウンロードが開始され、完了するとチャットエリアに通知されます。

**注意:**
- サーバーとクライアントを同じマシンで実行する場合、クライアントのIPアドレスには `localhost` または `127.0.0.1` を指定してください。
- サーバーを起動する前にクライアントで接続を試みると、接続エラーが発生します。必ずサーバーを先に起動してください。
- 複数のクライアントを起動したい場合は、上記コマンドを必要な数だけ実行してください。
