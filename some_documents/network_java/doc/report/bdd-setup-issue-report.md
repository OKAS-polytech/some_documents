# BDD環境構築に関する不具合レポート

## 1. 概要
本プロジェクトにおいて、当初計画していたふるまい駆動開発（BDD）の導入にあたり、テスト実行環境の構築で解決困難な問題が発生した。
本レポートは、発生した問題、試行した解決策、および最終的な結論を記録するものである。

## 2. 発生した問題
Maven環境下でCucumber 7とJUnit 5を連携させ、BDDのテストを実行しようとしたところ、Mavenがテストを一切発見できずにビルドが失敗する問題が継続的に発生した。

**主なエラーメッセージ:**
- `org.junit.platform.suite.engine.NoTestsDiscoveredException: Suite [...] did not discover any tests`
- `TestEngine with ID 'junit-platform-suite' failed to discover tests`

この問題により、BDDのサイクル（失敗するテストの記述 -> 実装）を開始することができなかった。

## 3. 試行した解決策と結果
問題解決のために、以下の設定変更と修正を試みた。

1.  **テストランナー(`CucumberTest.java`)の`glue`パス指定**
    - **内容**: `@ConfigurationParameter`で`cucumber.glue`プロパティを設定し、ステップ定義のパッケージを明示した。
    - **結果**: 状況は変わらず、`NoTestsDiscoveredException`が継続した。

2.  **`pom.xml`への`junit-jupiter-engine`依存関係の追加**
    - **内容**: テスト実行エンジンの不足を疑い、`junit-jupiter-engine`を明示的にテストスコープの依存関係として追加した。
    - **結果**: 解決せず。

3.  **`maven-surefire-plugin`のバージョン変更**
    - **内容**: 当初使用していた開発版 (`3.0.0-M7`) から安定版 (`3.2.5`) に更新した。
    - **結果**: 解決せず。

4.  **テストランナークラスの廃止と`pom.xml`での直接実行**
    - **内容**: `CucumberTest.java`を削除し、Surefireプラグインの`<configuration>`で直接フィーチャーファイルの場所を指定する方式に変更した。
    - **結果**: テストが全く実行されず、ビルドは成功したが0件のテスト実行という結果になった。

5.  **テストランナーの検索パスの絞り込み**
    - **内容**: `@SelectClasspathResource`で指定するパスを、プロジェクト全体からフィーチャーファイルが格納されている特定のパッケージに限定した。
    - **結果**: 解決せず。エラーメッセージに変化は見られなかった。

## 4. 原因の考察
複数の設定を試行したが問題が解決しなかったことから、原因は単一の設定ミスではなく、使用しているツール群（Cucumber 7, JUnit 5, Maven Surefire Plugin 3.x, および現在のサンドボックス環境）の特定のバージョンの組み合わせによる互換性の問題である可能性が高いと推測される。
特に、`junit-platform-suite`エンジンがCucumberのテストを動的に発見するプロセスに、環境固有の何らかの障害が発生していると考えられる。

## 5. 結論
上記の問題により、BDD環境の安定稼働にはさらなる調査が必要と判断した。
プロジェクトの遅延を避けるため、開発アプローチをBDDから**テスト駆動開発（TDD）**に切り替えることとした。TDDは標準のJUnit 5のみを使用するため、環境構築の問題を回避し、安定したテスト実行が可能である。
