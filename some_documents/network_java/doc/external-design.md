# 外部設計書

## 1. 概要
本ドキュメントは、「Javaで作るFTPツール」の外部設計を定義する。
要件定義書に基づき、システムのアーキテクチャ、画面仕様、通信プロトコルなどを定める。

## 2. システムアーキテクチャ
- Javaのソケット通信を利用したクライアントサーバー（C/S）モデルを採用する。
- サーバーは中央集権的にファイルの管理とクライアント間の通信を中継する。
- クライアントはGUIを通じてサーバーに接続し、各種機能を利用する。

![システム構成図](artifacts/system-architecture.puml)

## 3. 画面仕様
### 3.1. サーバーGUI
- 起動時にポート番号を指定してサーバーを開始する。
- 接続中のクライアント一覧を表示するエリアを設ける。
- サーバーのイベント（クライアント接続、ファイル送受信など）を表示するログエリアを設ける。

```
+-------------------------------------------------+
| サーバー管理画面                                |
+-------------------------------------------------+
| Port: [ 8080 ] [ サーバー開始 ] [ サーバー停止 ] |
+-------------------------------------------------+
| 接続中クライアント:                             |
| - client_1 (192.168.1.10)                       |
| - client_2 (192.168.1.11)                       |
+-------------------------------------------------+
| サーバーログ:                                   |
| [2023-10-27 10:00:00] サーバーを開始しました。  |
| [2023-10-27 10:01:15] client_1が接続しました。  |
+-------------------------------------------------+
```

### 3.2. クライアントGUI
- サーバーのIPアドレスとポート番号、ユーザー名を入力して接続する。
- サーバー上のファイル一覧を表示するエリアを設ける。
- ファイルのアップロード、ダウンロードを行うボタンを配置する。
- 他のクライアントとチャットを行うためのメッセージ入力欄と表示エリアを設ける。

```
+-------------------------------------------------------------------+
| クライアント画面 - [ ユーザー名 ]                                 |
+-------------------------------------------------------------------+
| IP: [ 192.168.1.1 ] Port: [ 8080 ] [ 接続 ] [ 切断 ]              |
+-------------------------------------------------------------------+
| サーバーファイル一覧:                 | チャット                  |
| - file_a.txt                          | [user_2]: こんにちは！    |
| - image.jpg                           | [自分]: はじめまして。    |
| [ アップロード ] [ ダウンロード ]     |                           |
+-------------------------------------------------------------------+
| メッセージ: [                               ] [ 送信 ]            |
+-------------------------------------------------------------------+
```

## 4. 通信プロトコル
クライアントとサーバー間の通信は、テキストベースのシンプルなプロトコルを使用する。
コマンドとデータは特定の区切り文字（例: `: `）で分割する。

| コマンド | 説明 | 送信元 -> 送信先 | 例 |
| --- | --- | --- | --- |
| `CONNECT` | サーバーに接続を要求する | Client -> Server | `CONNECT: user_1` |
| `LIST` | ファイル一覧を要求する | Client -> Server | `LIST` |
| `UPLOAD` | ファイルのアップロードを開始する | Client -> Server | `UPLOAD: file.txt` |
| `DOWNLOAD`| ファイルのダウンロードを要求する | Client -> Server | `DOWNLOAD: image.jpg` |
| `MSG` | チャットメッセージを送信する | Client -> Server | `MSG: こんにちは` |
| `BROADCAST`| メッセージを全クライアントに配信 | Server -> Client | `BROADCAST: [user_1]: こんにちは` |
| `FILE_LIST`| ファイル一覧をクライアントに送信 | Server -> Client | `FILE_LIST: file1.txt,file2.jpg` |
