# 内部設計書

## 1. 概要
本ドキュメントは、「Javaで作るFTPツール」の内部設計を定義する。
外部設計書に基づき、プログラムのクラス構造、主要なメソッド、コンポーネント間の連携などを定める。

## 2. クラス設計
本システムは、主に以下のパッケージで構成される。
- `com.example.ftp.server`: サーバー機能関連のクラス
- `com.example.ftp.client`: クライアント機能関連のクラス
- `com.example.ftp.gui`: GUI関連のクラス
- `com.example.ftp.chat`: チャット機能関連のクラス

詳細はクラス図を参照。

![クラス図](artifacts/class-diagram.puml)

### 2.1. サーバーパッケージ (`com.example.ftp.server`)
- **`Server`**: サーバーのメインクラス。クライアントからの接続を待ち受け、`ClientHandler`スレッドを作成する。
  - `main()`: サーバーを起動する。
  - `startServer()`: 指定されたポートでサーバーソケットを開く。
- **`ClientHandler`**: 各クライアントとの通信を担当するスレッドクラス。
  - `run()`: クライアントからのコマンドを受信し、処理を振り分ける。
  - `sendMessage()`: クライアントにメッセージを送信する。
  - `uploadFile()`: ファイルアップロード処理を行う。
  - `downloadFile()`: ファイルダウンロード処理を行う。

### 2.2. クライアントパッケージ (`com.example.ftp.client`)
- **`Client`**: クライアントのメインクラス。サーバーへの接続と、GUIとの連携を行う。
  - `main()`: クライアントGUIを起動する。
  - `connectToServer()`: サーバーに接続する。
  - `sendCommand()`: サーバーにコマンドを送信する。
  - `receiveMessage()`: サーバーからのメッセージを受信する。

### 2.3. GUIパッケージ (`com.example.ftp.gui`)
- **`ServerFrame`**: サーバー側のGUIクラス。`JFrame`を継承する。
  - ログ表示用の`JTextArea`、クライアント一覧表示用の`JList`などを持つ。
- **`ClientFrame`**: クライアント側のGUIクラス。`JFrame`を継承する。
  - ファイル一覧、チャット表示、各種ボタンなどを持つ。

### 2.4. チャットパッケージ (`com.example.ftp.chat`)
- **`ChatMessage`**: チャットメッセージを表すデータクラス。
  - 送信者、メッセージ本文、タイムスタンプなどの情報を持つ。

## 3. データフロー
1. クライアントがGUIから接続情報を入力し、`Client`クラスがサーバーに接続要求を送信する。
2. サーバーの`Server`クラスが接続を受け付け、新しい`ClientHandler`スレッドを生成する。
3. クライアントがGUI操作（例: ファイルアップロード）を行うと、`Client`クラスが対応するコマンドをサーバーに送信する。
4. `ClientHandler`がコマンドを受信し、ファイル操作やチャットメッセージのブロードキャストなど、適切な処理を実行する。
5. 処理結果や受信メッセージは、`Client`クラスを通じてクライアントGUIに反映される。
