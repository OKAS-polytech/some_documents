# 要件定義書

## 1. 概要

本ドキュメントは、「Javaで作るFTPツール」の要件を定義するものである。
このツールは、Javaのソケット通信を用いて、ファイル転送とチャット機能を備えたクライアントサーバーアプリケーションとして開発する。

## 2. 機能要件

### 2.1. ファイル転送機能
- クライアントからサーバーへファイルをアップロードできること。
- サーバーからクライアントへファイルをダウンロードできること。
- サーバー側で、アップロードされたファイルを指定のディレクトリに保存すること。

### 2.2. チャット機能
- クライアント間でリアルタイムにテキストメッセージを送受信できること。
- 送信されたメッセージは、接続している全クライアントにブロードキャストされること。

### 2.3. GUI機能
- ユーザーが直感的に操作できるGUIを提供すること。
- サーバーGUIには、接続中のクライアント一覧や、送受信ログを表示すること。
- クライアントGUIには、ファイル一覧の表示、アップロード・ダウンロードボタン、チャットウィンドウを設けること。

### 2.4. 接続管理機能
- サーバーは複数のクライアントからの接続を同時に受け付けられること。
- クライアントは、サーバーのIPアドレスとポート番号を指定して接続できること。

## 3. 非機能要件

### 3.1. 性能
- 社内LAN環境において、数MB程度のファイルをストレスなく転送できること。
- チャット機能は、遅延なくリアルタイムにメッセージを送受信できること。

### 3.2. セキュリティ
- （本プロジェクトの学習目的上、高度なセキュリティは考慮しない）

### 3.3. プラットフォーム
- Java実行環境（JRE）がインストールされているWindows, macOS, Linux上で動作すること。
